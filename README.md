# My KeePassXC

My personal fork of [KeePassXC](https://github.com/keepassxreboot/keepassxc), kept up to date with the latest KeePassXC release, with changes to suit my own preferences. It is unofficial and not affiliated with or endorsed by the KeePassXC team.

It isn't meant to replace or compete with the original. Others are welcome to use or borrow from it, with no guarantees.

## Changes

Each change lives on its own branch so it's easy to review, and is merged into the default branch.

- **Passkey column** (`feature/passkey-column`): an entry list column that shows an icon when the entry has a passkey.
- **SSH agent column** (`feature/ssh-agent-column`): an entry list column that shows an icon when the entry has SSH agent (KeeAgent) settings attached.

## Building

Build it from source like KeePassXC itself. See [INSTALL.md](INSTALL.md) for the steps and dependencies. No prebuilt binaries are provided.
